# TDD Scaffolder

## 概要
このスキルは、コードの実装を開始する前に、要件定義や設計書に基づいたテストコードの雛形（Scaffold）を自律的に生成するためのガイドラインです。

## 手順
1. **要件の分析**:
   実装対象のIssueや `spec.md` を読み込み、テストすべき入力・出力・境界値・エラーケースを洗い出す。
2. **テストフレームワークの確認**:
   プロジェクトの言語や環境に応じたテストフレームワーク（Jest, Pytest, Go testなど）を確認する。
3. **テストの雛形作成**:
   実際の実装コードを書く前に、以下を含むテストコードを作成する。
   - 正常系テスト（Happy path）
   - 異常系テスト（Edge cases, Error handling）
   - 必要なモックやスタブのセットアップ
4. **テストの失敗確認（Red）**:
   テストを実行し、実装が存在しないためにテストが失敗すること（Red状態）を確認する。
5. **実装フェーズへの移行**:
   テストが失敗することを確認した後、初めて実装フェーズ（Green状態を目指す）へと移行する。
