# Log Analyzer

## 概要
このスキルは、ビルドエラーやテスト失敗が発生した際に、人間にすぐ助けを求めるのではなく、エージェントが自律的にエラー原因を特定し、修正案を適用して検証するループを回すためのガイドラインです。

## 手順
1. **ログの収集と構造化**:
   - 失敗したコマンドの標準出力/標準エラー出力を取得する。
   - ログから「エラーの根本原因（Exception, Stack Trace）」となる重要な部分を抽出する。
2. **原因の推論 (`<thinking>`)**:
   - エラーの原因を推論し、必要であればコード検索で関連するソースコードを確認する。
   - 既知のライブラリのバグや仕様変更が疑われる場合は、Web検索を利用して情報を補完する。
3. **修正計画の立案 (`<plan>`)**:
   - どのような変更を加えればエラーが解決するか、最小限の差分での修正案を計画する。
4. **適用と再検証 (Iterate)**:
   - 修正を適用し、再度テストまたはビルドコマンドを実行する。
   - 解決するまでこのループを回す（最大3〜5回）。上限に達しても解決しない場合のみ、ここまでの調査ログをまとめて人間に報告・相談する。
