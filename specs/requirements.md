# システム要件定義書: アルゴ（algo）Web対戦システム

## 1. プロジェクト概要

### 1.1 背景と目的
「アルゴ（algo / Coda / Da Vinci Code）」は、算数オリンピック委員会・東京大学数学科の学生有志・数学者ピーター・フランクル氏らが共同開発した、伏せられた相手の数字カードを推理する大人気頭脳派ボードゲームです。
本プロジェクトは、このアルゴの魅力をWeb上で手軽かつ本格的に体験できるWebアプリケーションを構築することを目的とします。
まずは一人でいつでも手軽に思考戦を楽しめる**「CPU対戦モード」**を最優先で実現し、将来的には離れた友人や全国のプレイヤーとリアルタイムで対戦できる**「オンライン対戦モード」**へ拡張可能な設計を採用します。

### 1.2 コアバリュー
1. **高い論理的思考体験**: ルールに忠実なカード配置・開示ルール、論理的消去法に基づいたCPU思考AI。
2. **直感的で洗練されたUI/UX**: 物理カードの質感・伏せ状態・開示アニメーションをWeb上で美麗に再現。
3. **拡張性と堅牢性**: 将来のWebSocketリアルタイムオンライン対戦・ユーザー戦績保存に耐えうるモジュール化アーキテクチャ。

## 2. アルゴ ゲームルール定義

### 2.1 カードコンポーネント
- **カード総数**: 全24枚
  - **黒カード (Black)**: 0 〜 11（各1枚、計12枚）
  - **白カード (White)**: 0 〜 11（各1枚、計12枚）
- **カードの公開属性**:
  - `表向き (Open)`: 数字と色が全プレイヤーに見えている状態。
  - `裏向き (Closed)`: 色（黒/白）のみ全プレイヤーに見えており、数字は所有者（自分）にのみ見えている状態（相手からは「?」）。

### 2.2 カードの並び順ルール（最重要規約）
全プレイヤーの手札は、左から右へ以下の順序関係で厳密にソートされて並ぶ：
1. **小さい数字が左、大きい数字が右**。
2. **同じ数字の場合は「黒」が左、「白」が右**（黒 < 白）。
- 順序関係: `(0, 黒) < (0, 白) < (1, 黒) < (1, 白) < ... < (11, 黒) < (11, 白)`

### 2.3 2人対戦（CPU対戦）ゲームフロー
1. **初期配置**:
   - 24枚をシャッフル。
   - プレイヤーとCPUに山札から4枚ずつ配る。
   - 各プレイヤーは自分の4枚を見て、上記並び順ルールに従い左から右へ「裏向き」で整列させる。
   - 残り16枚は裏向きの「山札（デッキ）」として中央に配置。
   - 先攻・後攻をランダム（またはユーザー選択）で決定。

2. **手番（ターン）の実行**:
   - **Step 1: ドロー**:
     - 山札からカードを1枚引く（手番プレイヤーのみ数字を確認）。
     - ※山札が0枚の場合はドローをスキップしてアタックへ進む。
   - **Step 2: アタック（推理）**:
     - 手番プレイヤーは、相手の「裏向き」のカードを1枚選択する。
     - そのカードの数字（0〜11）を予想して宣言する（色は見えているため数字のみ宣言）。
   - **Step 3: 判定と分岐**:
     - **【的中（正解）した場合】**:
       - 相手のそのカードを表向き（Open）にする。
       - **勝利判定**: 相手の全カードが表向きになった場合、直ちにアタック側の勝利でゲーム終了。
       - まだ相手に裏向きカードがある場合、アタック側は以下のいずれかを選択：
         1. **コンティニュー（続けてアタック）**: ドローはせず、引いたカードを手元に保持したまま、再度相手の裏向きカードを指定してアタック。
         2. **ステイ（手番終了）**: 引いたカードを自分の手札の並び順ルール通りの正しい位置に「裏向き」で挿入・配置して手番を相手に渡す。
     - **【ハズレ（不正解）の場合】**:
       - 今回引いたカードを表向き（Open）にして、自分の手札の並び順ルール通りの正しい位置に配置する（相手に貴重なヒントを与えるペナルティ）。
       - 手番は終了し、相手のターンへ移行。

3. **勝敗条件**:
   - 先に相手のすべてのカードを表向き（Open）にしたプレイヤーの勝利。

## 3. 機能要件

### 3.1 CPU対戦機能（Phase 0 / Phase 1 コア機能）
- **難易度選択**:
  - `Easy (初級)`: 既に場に見えているカードや自分の手札と矛盾しない候補の中からランダムに予想。
  - `Normal (中級)`: 左右のカードの範囲制限（例: 左が黒3、右が白7なら、間は白3〜黒7のいずれか）を考慮し、論理的候補の中から等確率で選択。
  - `Hard (上級)`: 過去のアタック履歴（ハズレ情報）も記憶・排除し、残存カードの出現確率や情報量を計算して最も期待値の高い推理を実行。
- **手番アニメーション・思考時間**:
  - CPUが即答せず、1〜1.5秒の思考ウェイトや「Thinking...」アニメーションを挟み、対人戦のような臨場感を演出。
- **ゲームログ・履歴表示**:
  - 各ターンのアタック（「CPUが白の2枚目を [5] と推理 -> 的中！」など）の履歴ログを画面上に表示。

### 3.2 UI/UX機能
- **ボード画面**:
  - 相手（CPU）手札エリア（上部）
  - 中央エリア: 山札（残枚数表示）、引いたカード、アタック操作パネル、ゲームステータス
  - 自分（プレイヤー）手札エリア（下部）
  - 対戦ログパネル（右側または下部）
- **操作性**:
  - 相手の裏向きカードをクリックして選択 -> 数字キーパッドまたはセレクターで直感的に数字を入力。
  - アタック成功時の「アタック続行」または「ステイ」の明確なダイアログ選択。
  - ルール確認ガイドモーダル（ゲーム中いつでもルールや並び順規約を確認可能）。
- **レスポンシブ対応**:
  - PCデスクトップおよびスマートフォン（モバイル）の画面幅に対応。

### 3.3 将来拡張（オンライン対戦機能 - Phase 2構想）
- ルーム作成・合流（Room ID / URL共有）
- WebSocket（Supabase Realtime / Socket.io）による双方向リアルタイム同期
- チャット・リアクション機能
- 観戦モード
