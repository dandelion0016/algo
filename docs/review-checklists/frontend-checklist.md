# フロントエンド レビュー観点チェックリスト (frontend-checklist.md)

本チェックリストは、フロントエンドUI/UX実装およびPRレビュー時に検証すべき品質・受入観点を定義します。

## 1. レスポンシブ・マルチデバイス表示検証（今回の再発防止観点）
- [ ] **全ブレークポイントでのメタ情報視認性**:
  - スマートフォン（幅 < 640px）、タブレット（640px 〜 1023px）、デスクトップ（>= 1024px）の全解像度において、バージョン表記（`getAppVersion()`）やシステムメタ情報が不意に `hidden lg:block` 等で非表示・見切れになっていないか。
  - モバイルの縦長画面（高さ 600px〜850px）でモーダルやフッターがスクロールバーや他要素と重複していないか。
- [ ] **タッチ・キーボード操作性**:
  - 2桁数字入力（10, 11）や物理キーボード操作、モバイルソフトウェアキーボード表示時のレイアウト崩れがないか。

## 2. バージョン埋め込み・クライアントバンドル整合性
- [ ] **環境変数の静的置換**:
  - クライアントコンポーネントにおける `NEXT_PUBLIC_APP_VERSION` の参照が正しくビルド時インライン展開されること。
  - 未注入時・ローカル開発時でも異常停止せず、意図通りの表記が得られること。

## 3. テスト完全性 ＆ E2E
- [ ] **Playwright E2E**:
  - 主要な操作画面（セットアップ、ゲーム盤、リザルト）においてバージョンバッジが表示・確認できること。
- [ ] **DOMテスト**:
  - `@testing-library/react` による状態遷移・ユーザーイベントテストがすべてパスしていること。
