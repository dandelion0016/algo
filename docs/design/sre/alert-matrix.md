# SRE 監視アラートマトリクス (Alert Matrix)

## 1. アラート重要度レベル定義

| 重要度 | レベル名 | 定義・影響度 | 初動対応目標 (MTTA) | 通知チャネル |
| :---: | :--- | :--- | :---: | :--- |
| **P1** | **Critical** | システム全面停止、主要業務停止、深刻なデータ破損・漏洩 | 即時 (10分以内) | 24/7 自動架電・PagerDuty ＋ Slack緊急 |
| **P2** | **Major** | 一部機能不全、大幅なレイテンシ悪化（SLO侵害リスク高） | 30分以内 | PagerDuty ＋ Slack（メンション付き） |
| **P3** | **Warning** | リソース使用率逼迫、エラーレート軽度上昇、冗長構成の一部障害 | 2時間以内 | Slack通知 (運用チャンネル) |
| **P4** | **Info** | 定期ジョブ完了通知、軽微な異常予兆、メンテ情報 | 翌営業日 | Slack通知 (ログ・通知チャンネル) |

## 2. 監視アラート定義一覧

| アラートID | 監視対象メトリクス | 検知条件・しきい値 | 判定期間 | 重要度 | 自動アクション / 初動対応 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| `ALM-001` | 外形ヘルスチェック (`/health`) | ステータスコード != 200 | 1分間連続 2回 | **P1** | ECSタスク自動再起動、オンコール呼出 |
| `ALM-002` | API 5xx エラーレート | 5xx率 > 1.0% | 5分間継続 | **P1** | 直近デプロイの自動ロールバック検討 |
| `ALM-003` | API レスポンス時間 (p95) | p95 > 1,000ms | 5分間継続 | **P2** | DBスロークエリ調査、オートスケール発動 |
| `ALM-004` | Aurora/RDS CPU使用率 | CPU使用率 > 80% | 10分間継続 | **P2** | 読取レプリカへのトラフィックオフロード |
| `ALM-005` | DB コネクションプール利用率 | 利用率 > 85% | 3分間継続 | **P2** | コネクションリーク調査、プーラー設定点検 |
| `ALM-006` | セキュリティポリシー遮断急増 | 拒絶数 > 50件 / 分 | 3分間継続 | **P1** | WAFによる送信元IP一時遮断、インシデント起票 |
| `ALM-007` | バックアップ失敗 | 日次スナップショット失敗 | 1回 | **P2** | 手動スナップショット即時実行 |
| `ALM-008` | ECS メモリ使用率 | メモリ使用率 > 75% | 15分間継続 | **P3** | タスクスケールアウト実行 |
| `ALM-009` | ディスク空き容量 | 空き容量 < 20% | 15分間継続 | **P3** | ログローテーション確認、ストレージ拡張 |
