# UI仕様 ＆ 画面詳細設計書: アルゴ（algo）Web対戦システム

## 1. デザインシステム ＆ カラーパレット

### 1.1 デザインコンセプト
- **「北欧モダン × 洗練された知性」**:
  - アルゴの持つ「高度な論理数学パズル」の知的印象と、親しみやすく温かみのあるボードゲームの質感を両立。
  - パステルイエローとスカイブルーの幾何学ダイヤパターン（アーガイル模様）をヘッダーやアクセントに配置し、上品なコントラストを演出。
  - カードは実物のプラスチック・タイルを想起させる立体感（微細なグラデーションとソフトシャドウ）を再現。

### 1.2 カラーパレット定義

| カラートークン名 | カラーコード | 役割・用途 | アクセシビリティ・コントラスト配慮 |
| :--- | :--- | :--- | :--- |
| `algo-yellow` | `#FCF97A` | ブランドプライマリカラー、選択ハイライト、アタック的中バッジ、決定ボタン | 背景色として使用時、文字色は `slate-950`（高コントラスト比）を採用 |
| `algo-yellow-light` | `#FEFDDB` | 成功メッセージ背景、ガイダンスパネル背景 | 柔らかい視覚フィードバック用 |
| `algo-yellow-dark` | `#E6E24E` | イエローボタンの境界線、ホバー時ボーダー | 視認性向上のためのエッジ定義 |
| `algo-blue` | `#7BA6EF` | ブランドセカンダリカラー、ターンインジケータ、ドローハイライト、選択リング | 白文字および濃色背景との視認性を確保（WCAG AA準拠） |
| `algo-blue-light` | `#EEF4FD` | ガイダンス枠背景、アクティブプレイヤーカード背景 | 爽快感と集中力を高めるペールブルー |
| `algo-blue-dark` | `#4F82DF` | アタックボタンのグラデーション終点、アクティブ時の強調 | 強い視線誘導用 |
| `algo-sand` | `#FAF9F5` | アプリ全体のベース背景色 | 純白ではなく目に優しいオフホワイト/サンド |
| `algo-navy` | `#1E2A44` | メインテキスト、重要見出し、ダークボタン背景 | 漆黒ではなく深いネイビーで洗練された印象 |
| `algo-slate` | `#334155` | サブテキスト、枠線、非アクティブ要素 | 落ち着いたニュートラルグレー |
| **カード（黒）** | `zinc-800` 〜 `zinc-950` | 黒カードの質感（深いチャコール〜漆黒グラデーション） | 白文字（`#FFFFFF`）との明確なコントラスト |
| **カード（白）** | `white` 〜 `slate-100` | 白カードの質感（ソフトシャドウ付きピュアホワイト） | 黒文字（`zinc-900`）との明確なコントラスト |

## 3. 各コンポーネント詳細仕様

### 3.1 `SCR-001: SetupModal.tsx`
- **役割**: 新規対戦の初期設定（人数・持ち時間・難易度・ニックネーム・サウンド）の管理。
- **Props 仕様**:
  ```typescript
  export interface SetupModalProps {
    playerCount: PlayerCount;
    difficulty: Difficulty;
    timeLimit: TimeLimit;
    onSelectPlayerCount: (count: PlayerCount) => void;
    onSelectDifficulty: (diff: Difficulty) => void;
    onSelectTimeLimit: (limit: TimeLimit) => void;
    onStartGame: () => void;
    onOpenRules: () => void;
    onOpenTutorial?: () => void;
    onOpenStats?: () => void;
    isSoundMuted?: boolean;
    isSoundEnabled?: boolean;
    onToggleSound?: () => void;
    userId?: string;
  }
  ```
- **UI機能**:
  - **ニックネーム入力（`input-nickname`）**: 最大15文字、Cookie永続化（`algo_nickname`）、XSSサニタイズ。
  - **対戦相手構成プレビュー（Roster）**: 選択人数に応じた対戦相手（CPU アル、CPU ゴオ、CPU ルウ）のアバター、初期手札枚数、山札残数をカードバッジで可視化。
  - **戦績・サウンドボタン**: ツールバーにWeb Audio音量トグル（`Volume2`/`VolumeX`）、戦績モーダル呼出（`Trophy`）。
  - **バージョン表示**: 右上に `getAppVersion()` によるビルドメタデータ/Gitコミットバージョン表示。

### 3.2 `SCR-002: GameBoard.tsx`
- **役割**: ゲーム盤面の統合コンテナ、状態（`GameState`）の集中管理、Web Audio音響、モバイルHUD統括。
- **UI機能**:
  - **サウンドトグル（Web Audio API）**: BGMおよび効果音（ドロー音、アタック成功ファンファーレ、ハズレ音、K.O.バースト音）の一括ON/OFF。
  - **モバイル対応メニュー**: 画面幅 768px 未満でヘッダーボタンを折りたたむ `☰ メニュー` ドロップダウン。
  - **残弾トラッカーHUD**: デスクトップでは右サイドバー常時表示、モバイルではフローティングFABボタン（`Target`）押下でボトムシート展開。
  - **AIヒントアドバイザー**: 手番中にAIヒントモーダルを呼び出すFAB/ヘッダーボタン（1戦1回消費、タイマー連動）。

### 3.3 `SCR-004: AttackModal.tsx`
- **役割**: プレイヤーの数字推理モーダル。
- **Props 仕様**:
  ```typescript
  interface AttackModalProps {
    targetPlayerName: string;
    targetIndex: number;
    targetColor: CardColor;
    onConfirmGuess: (guessedNumber: number) => void;
    onCancel: () => void;
    disabledNumbers?: number[];        // 既知数字（オープン済み/自手札）
    possibleNumbers?: number[];        // 推理候補数字リスト (Issue #42)
    assistEnabled?: boolean;           // 初心者アシストフラグ
    failedNumbers?: number[];          // 過去に外れた失策数字リスト (Issue #43)
    remainingDeckNumbers?: number[];   // 同色の未確定残弾配列 (Issue #113)
  }
  ```
- **UI機能**:
  - **候補数字バッジ**: 両隣の確定カード等から論理的に絞り込まれた数字に「候補」バッジを付与。
  - **失策数字グレーアウト**: 当該カードに対して以前推理して外れた数字を「失策」表示にして二重ミスを抑止。
  - **トラッカー残弾連動**: 全24枚の残弾データに基づき、山札・手札に存在しない数字を機械的にハイライト/非活性化。
  - **テンキー・キーボードショートカット**: 0〜11の直接入力、矢印キー移動、Enter確定、Escapeキャンセル。

### 3.4 `SCR-007: ResultModal.tsx`
- **役割**: 対戦決着時の独立結果モーダル。
- **Props 仕様**:
  ```typescript
  export interface ResultModalProps {
    isOpen: boolean;
    winner: Player | null;
    humanPlayer: Player | null;
    players: Player[];
    logs: AttackLog[];
    playerCount: PlayerCount;
    difficulty: Difficulty;
    timeLimit: TimeLimit;
    onPlayAgain?: () => void;
    onRestart?: () => void;
    onReturnSetup: () => void;
    onClose?: () => void;
  }
  ```
- **UI機能**:
  - **勝敗メッセージ・紙吹雪**: 勝利時は `ConfettiEffect` による色鮮やかな祝賀パーティクルアニメーション。
  - **戦闘スタッツ**: ターン数、総アタック回数、的中率（%）、生存カード枚数の構造化表示。
  - **手札の答え合わせ（Review Hands）**: ゲーム終了時に全プレイヤー（CPU含む）の手札全カードをオープン状態で並べて表示し、伏せカードの推理の答え合わせが可能。

### 3.5 `SCR-009: AttackResultModal.tsx`
- **役割**: プレイヤーのアタック成否（的中/ハズレ）およびドローカードの展開案内モーダル。
- **Props 仕様**:
  ```typescript
  export interface AttackResultModalProps {
    isOpen: boolean;
    data: AttackResultData | null;
    onConfirm: () => void;
  }
  ```
- **UI機能**:
  - アタック結果（的中時はグリーンチェック、ハズレ時はレッドクロス）とメッセージ。
  - 的中時は「続けてアタック」または「ステイ（手札に加える）」への遷移案内。
  - Space / Enter / Escape キーによるワンタップ確認操作。

- **Props 仕様**:

### 3.7 `SCR-011: HintModal.tsx`
- **役割**: AIによる一手アドバイザー（1戦1回制限）。
- **Props 仕様**:
  ```typescript
  export interface HintModalProps {
    isOpen: boolean;
    onClose: () => void;
    hint: HintResult | null;
    remainingHints: number;
    onSelectTarget?: (playerId: string, cardIndex: number) => void;
    canSelectTarget?: boolean;
    isTimedMatch?: boolean;
  }
  ```
- **UI機能**:
  - **100% 確定マス表示**: 論理消去法により数字が1択に絞り込めるカードが存在する場合、確定バッジとともに提示。
  - **最善候補マス表示**: 確定マスがない場合、候補数が最も少なく的中率が高いカードと推定数字リストを提示。
  - **タイマー警告**: 持ち時間対戦中の場合、「タイマーは停止しません」の警告バッジを表示。
  - **「このカードを狙う」ボタン**: ヒント画面から直接対象カードをフォーカス可能。

### 3.11 `SCR-015: TutorialModal.tsx`
- **役割**: 6ステップ対話型インタラクティブチュートリアル。
- **Props 仕様**:
  ```typescript
  export interface TutorialModalProps {
    isOpen: boolean;
    onClose: () => void;
    onComplete?: () => void;
    initialStep?: number;
    isTimedMatch?: boolean;
  }
  ```
- **UI機能**:
  - **Step 1: アルゴの基本ルール**: 並び順の原則（左から小さい順、同数は黒が左）。
  - **Step 2: カードをドローしよう**: 実際に山札をクリックしてカードを引く体験。
  - **Step 3: どこに入る？並び順の謎**: 引いたカードが手札のどの位置に入るかを推理。
  - **Step 4: 相手のカードをアタック！**: 相手の伏せカードを選び、数字を予想して当てる体験。
  - **Step 5: 続けるかステイか？**: 的中後の戦略的判断（アタック継続 vs ステイ収納）。
  - **Step 6: チュートリアル修了！**: トロフィー演出と本番対戦への誘導。

- **UI機能**:
  - `componentDidCatch` により未処理例外を捕捉し、ユーザーフレンドリーなフォールバック画面を表示。
  - 監査ロガー（`auditLogger`）と連携し、`CLIENT_CRASH` 監査イベント（エラー名、スタック、URL、ユーザーID）を自動送信。
  - 「ページを再読み込みする」ボタンによる安全なセッション復旧機能。
