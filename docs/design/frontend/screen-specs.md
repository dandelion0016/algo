# UI仕様 ＆ 画面詳細設計書: アルゴ（algo）Web対戦システム

## 1. デザインシステム ＆ カラーパレット

### 1.1 デザインコンセプト
- **「北欧モダン × 洗練された知性」**:
  - アルゴの持つ「高度な論理数学パズル」の知的印象と、親しみやすく温かみのあるボードゲームの質感を両立。
  - パステルイエローとスカイブルーの幾何学ダイヤパターン（アーガイル模様）をヘッダーやアクセントに配置し、上品なコントラストを演出。
  - カードは実物のプラスチック・タイルを想起させる立体感（微細なグラデーションとソフトシャドウ）を再現。

### 1.2 カラーパレット定義

| カラートークン名 | カラーコード | 役割・用途 | アクセシビリティ・コントラスト配慮 |
| :--- | :--- | :--- | :--- |

## 3. 各コンポーネント詳細仕様

### 3.1 `GameBoard.tsx`
- **役割**: ゲーム盤面の統合コンテナ、状態（`GameState`）の集中管理、ターン進行・タイマー・CPU実行キューのハンドリング。
- **主要State / Props**:
  - `gameState`: `playerCount`, `difficulty`, `timeLimit`, `remainingTime`, `deck`, `players`, `activePlayerIndex`, `drawnCard`, `phase`, `selectedTarget`, `logs`, `winner`
  - `isRuleModalOpen`: ルールモーダル開閉フラグ
  - `cpuStatusMessage`: CPU思考状態テキスト
- **主要メソッド**:
  - `initializeGame(count, diff, limit)`: デッキ生成（24枚）、プレイヤー別配布・整列、初期化
  - `handlePlayerDraw()`: プレイヤーによる山札ドロー（空の場合は直接対象選択へ）
  - `handleSelectTargetCard(playerId, cardIndex)`: アタック対象カード選択
  - `handleConfirmGuess(guessedNumber)`: 推理判定（的中時: OPEN ＆ 継続/ステイ選択、ハズレ時: ドローカード強制OPEN ＆ CPU移行）
  - `handlePlayerContinue()`: アタック成功後の「続けてアタック」
  - `handlePlayerStay()`: アタック成功後の「ステイ（引いたカードを伏せて手番終了）」

### 3.2 `CardComponent.tsx`
- **役割**: 単一カードのレンダリング（黒/白、表向き/伏せ、数字表示、アニメーション、選択・アタック可能状態表示）。
- **Props 仕様**:
  ```typescript
  interface CardComponentProps {
    card: Card;               // { id, color: 'black'|'white', number, isOpen }
    isOwner: boolean;         // 自分（人間）のカードかどうか（自分なら伏せでも数字を可視化）
    isSelected?: boolean;     // 現在アタック対象として選択中か
    isSelectable?: boolean;   // アタック可能カードとして選択可能か（脈動パルス表示）
    onClick?: () => void;     // クリックハンドラー
    size?: 'sm' | 'md' | 'lg';// サイズバリエーション（sm: 40x64px, md: 64x104px, lg: 96x144px）
    label?: string;           // 左からの位置ラベル（例: "#1", "#2"）
    isEliminated?: boolean;   // 脱落プレイヤーのカードか（グレースケール表示）
  }
  ```
- **状態ビジュアル表現**:
  - **黒カード**: `bg-gradient-to-b from-zinc-800 to-zinc-950 text-white`
  - **白カード**: `bg-gradient-to-b from-white to-slate-100 text-zinc-900 border-slate-200`
  - **伏せ中（自分）**: カード下部に `伏せ中` バッジ（アンバー色）を表示し、自分には数字が見えるが相手には秘密であることを明示。
  - **伏せ（相手）**: 中央に `?` マークを上品なセリフフォントで表示。
  - **アタック可能（脈動）**: `animate-attack-pulse` クラスにより、ボーダーとブルーのリングシャドウが脈動。
  - **選択中**: `border-algo-blue ring-4 ring-algo-blue/40 scale-105 z-10`

### 3.3 `AttackModal.tsx`
- **役割**: プレイヤーが対象カードの数字を0〜11の中から推理・決定するモーダル。
- **Props 仕様**:
  - `targetPlayerName`: 攻撃対象のプレイヤー名
  - `targetIndex`: 攻撃対象カードの左からのインデックス（0開始）
  - `targetColor`: 攻撃対象カードの色（`black` / `white`）
  - `onConfirmGuess(guessedNumber)`: アタック確定時コールバック
  - `onCancel()`: キャンセル時コールバック
  - `disabledNumbers`: 既にオープンされている、または自分の手札にある数字の配列
- **UI機能**:
  - 対象情報バナー（プレイヤー名、何番目の黒/白カードか）
  - 4列×3行の0〜11ボタングリッド
  - `disabledNumbers` に含まれる数字には「確認済」バッジを表示し、推論の補助情報を提示。
  - 数字選択前はアタックボタンを非活性化（誤送信抑止）。

### 3.4 `SetupModal.tsx`
- **役割**: 新規対戦の初期設定（人数・持ち時間・難易度）を直感的に選択するモーダル。
- **Props 仕様**:
  - `playerCount`: `2 | 3 | 4`
  - `difficulty`: `'easy' | 'normal' | 'hard'`
  - `timeLimit`: `0 | 15 | 30`
  - 各種選択コールバック、`onStartGame`、`onOpenRules`
- **UI機能**:
  - ブランドヘッダー＆ヒーローバナー表示
  - 3項目のボタントグル（アクティブ要素はイエロー/ブルーのハイライト枠線）
  - 各設定の説明ラベル（手札枚数、プレイスタイル、AI思考アルゴリズム）の明示

### 3.5 `GameLog.tsx`
- **役割**: 過去のアタック履歴（攻撃者、対象者、色、宣言数字、的中/ハズレ）のリアルタイムリスト表示。
- **Props 仕様**: `logs: AttackLog[]`
- **UI機能**:
  - 最新のログが最上部（降順表示）
  - 的中時はグリーン（`bg-emerald-50` ＋ チェックアイコン）
  - ハズレ時はグレー/ローズ（`bg-slate-50` ＋ ×アイコン）
  - スクロールコンテナ（デスクトップ時最大高さ480px、スマホ時最大高さ280px）

### 3.6 `RuleGuideModal.tsx`
- **役割**: アルゴの公式ルール（並び順、初期手札、手番フロー、勝利条件）を初心者にも分かりやすく図解するモーダル。
- **Props 仕様**: `isOpen: boolean`, `onClose: () => void`
- **UI機能**:
  - 4つのセクション分割（並び順の鉄則、人数別枚数表、手番ステップ、勝利条件）
  - カード順序例 `[黒0] → [白0] → [黒1] → ... → [白11]` の強調表示

## 4. 持ち時間タイマー演出仕様

### 4.1 タイマーモード
1. **30秒（標準テンポ・推奨）**: 初心者から上級者まで適度な長考とテンポを両立。
2. **15秒（早指しスピーディ）**: スリリングな即断即決を要求する上級者・スピードモード。
3. **無制限（0秒・マイペース）**: 時間を気にせず論理的消去法を極限まで計算できる練習モード。

### 4.2 タイマー演出仕様
- **通常時 (残り6秒以上)**:
  - スカイブルーの背景（`bg-algo-blue-light/60 border-algo-blue/30 text-algo-navy`）で残り秒数をカウントダウン。
- **警告パルス (残り5秒以下)**:
  - 背景がソフトレッド（`bg-rose-50 border-rose-300 text-rose-600`）へ反転。
  - `animate-pulse` および `ring-2 ring-rose-200` による点滅警告でユーザーへ迅速な入力を喚起。
- **時間切れ（0秒到達）強制オープン仕様**:
  - タイマーが0秒に達した瞬間、インターバルを即時停止。
  - 山札（未ドローの場合）または引いたカードを**表向き（`isOpen: true`）**でプレイヤーの手札の正しい位置に強制挿入（相手に情報を全開示するペナルティ）。
  - 対戦ログに「時間切れ！引いたカードがオープンペナルティとなり手番終了。」を記録。
  - 即座に手番を次プレイヤー（CPU等）へ自動交代。
