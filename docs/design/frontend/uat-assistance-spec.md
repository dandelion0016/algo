# 実機UAT自動化アシスト仕様書 (UAT Assistance Spec)

本ドキュメントは、**Phase 1（自律実装 ＆ 継続的受入・仕上げ）** において、人間ゲートキーパーの検証負荷（認知負荷・手動操作の手間）を極小化するため、エージェントチームが自律的に実行・提供する**UAT自動化アシストプロトコル**を定義します。

---

## 1. 目的と提供価値

1. **人間の目視受入の迅速化**:
   - 人間が一から手作業ですべての画面・フォームを入力確認するのではなく、エージェントが**E2Eテストシナリオ、画面キャプチャ（スナップショット）、実行結果レポート**を事前生成して提示。
   - 人間は「エビデンスを眺めて受入判断」し、「気になったピンポイントの部分のみ実機操作」に専念できる。
2. **小規模プロジェクトでの検証漏れ防止**:
   - 専任のQAチームが存在しない小規模チームでも、Playwright 等を用いた主要ユーザーフローの自律スキャンにより、リグレッションや壊れた導線を即座に検知。

---

## 2. 自動化アシストの3つの成果物

エージェントは、Phase 1 の各トピックブランチPR作成時およびフィードバック反映時において、以下のエビデンスを自動生成・提示します：

```text
【1. E2Eシナリオ自律実行】
  Playwright / Puppeteer を用いた主要ユースケースの自動実行
  （正常系フロー、バリデーションエラー系、権限ガード系）
      │
      ▼
【2. 視覚的エビデンス（スナップショット・録画）】
  各ステップでの画面キャプチャ、レスポンシブ表示（PC / モバイル）、
  HITL承認モーダルの表示確認スナップショット
      │
      ▼
【3. 人間向けUATサマリレポート（Markdown / HTML）】
  検証シナリオ一覧、合否ステータス、キャプチャ一覧、
  「人間が実機で特に確認すべき推奨ポイント」を整理したダッシュボード
```


## 4. 担当ロールと実行責任

- **フロントエンド担当 (`role:frontend/dev`, `role:frontend/rev`)**:
  - 主要画面のE2Eテストシナリオコード（`tests/e2e/`）の策定・保守。
  - レスポンシブ表示やモーダルのスナップショット収集。
- **システム運用・SRE担当 (`role:ops`)**:
  - CI環境またはローカルでのE2Eテスト自動実行パイプラインの整備。
  - テスト結果レポートの自動生成スクリプト提供。
- **管理者 (`role:manager`)**:
  - 人間へのUATサマリ提示と、実機フィードバックのIssue化統括。
