# アルゴ（algo）Web対戦システム

頭脳派ボードゲーム「アルゴ（algo）」をWeb上で手軽かつ本格的に遊べるWebアプリケーションです。
まずは一人でいつでも手軽に思考戦を楽しめる**「CPU対戦モード」**を最優先で実現し、将来的には離れた友人や全国のプレイヤーとリアルタイムで対戦できる**「オンライン対戦モード」**へ拡張します。

本プロジェクトは **Google Antigravity 自律型開発＆セキュリティガバナンス** に準拠して開発・運用されています。

---

## 🎮 アルゴ（algo）とは？

算数オリンピック委員会、東京大学数学科の学生有志、数学者ピーター・フランクル氏らが共同開発した、伏せられた相手の数字カードを推理する大人気推理カードゲームです。

### 基本ルール
1. **カード構成**: 黒（0〜11）12枚 ＋ 白（0〜11）12枚 ＝ 全24枚
2. **並び順の絶対ルール**:
   - 小さい数が左、大きい数が右。
   - 同じ数字の場合は「黒」が左（小さい扱い）、「白」が右。
   - `(0, 黒) < (0, 白) < (1, 黒) < (1, 白) < ... < (11, 黒) < (11, 白)`
3. **ゲーム進行（CPU対戦）**:
   - 初期手札4枚（裏向きでルール順に整列）、残り16枚は山札。
   - 手番では山札から1枚引き、相手の裏向きカードの数字を推理（アタック）。
   - **的中**: 相手のカードがオープン。さらにアタックを続けるか、手札に裏向きで加えてステイするか選べる。
   - **ハズレ**: 引いたカードを自分の手札にオープン（表向き）で配置（相手に情報がバレるペナルティ）。
   - 相手のカードをすべてオープンさせた方の勝利！

## 🛠 技術スタック

- **フロントエンド / フルスタック**: Next.js 15+ (App Router), React 19, TypeScript
- **スタイリング**: Tailwind CSS
- **アイコン**: Lucide React
- **テスト**: Vitest
- **ガバナンス / CI**: Antigravity Lifecycle Hooks, GitHub Actions

---

## 🚀 開発の進め方

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ユニットテスト実行
npm test
```
