PuzzleCabin について

思考する喜びを、すべての人へ。

PuzzleCabin（パズルキャビン）は、頭脳ゲームや論理パズルを通じて、日常の中で思考を深める豊かな時間を提供することを目的として立ち上げられたWebゲームプラットフォームです。

「わかりやすく、心地よく、深く楽しめる」をテーマに、最新のWeb技術（Next.js / TypeScript / AWS Serverless）を活用し、高速かつストレスフリーな動作環境を追求しています。PC・スマートフォンのどちらでも快適に動作し、煩わしい会員登録を行わずにすぐに遊べるオープンな設計を重視しています。
